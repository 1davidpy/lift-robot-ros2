遥操作控制

读取服务状态…

先开启设备采集，再开启控制与录制程序。启动程序不会使能电机。

等待读取当前控制模式。

01 检查连接02 使能对齐03 开始采集

长按 X 1.5 秒统一使能：摇杆回中、两中指松开，双臂归位后按两食指完成对齐，随后开放底盘和升降。所有设备必须就绪。

运行中短按 X：底盘和升降在原位停止 → 确认停稳 → 双臂返回 home → 关节停稳后移除双臂转矩。升降不回零、不改变高度。操作者须确认当前高度下双臂归位及失能不会碰撞或下落；故障时中止回位并保持双臂。

B / “停止全部”停止底盘和本次 CAN 升降运动、保持双臂，不执行回位、不移除双臂转矩。停止后短按 X 再请求停放，长按 X 重新准备。Y 预留。A 仍开始 / 成功结束录制；录制中的 B 同时打开失败菜单。

升降平台

左中指按住下降、右中指按住上升。松手或双键同按停止，保留升降许可；到行程内缩边界停住。换向先松开两键再按，重新运动前等待停稳。停车回位期间忽略握键运动。独立设备停车会中止统一运行。

软件停止有执行延迟，不替代硬件急停。升降锁闸位是控制输出，没有机械闭合传感器；保留板端已有上电回中策略。统一模式不支持独立键盘使能。
