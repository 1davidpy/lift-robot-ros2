最终全量构建：**10/10 ROS 包成功**，见 `log/build-final.log`。最终测试：**18 tests，0 errors，0 failures，0 skipped**，见 `log/test-final.log`。整机集成测试耗时 14.58 秒，整套测试耗时 20.9 秒。

回归包含 Quest 校验/坐标/滤波、双臂 IK 收敛及限幅、假海康 SDK ABI/像素/异常输入、存储哈希、KH 通道映射及整机集成。集成程序逐行检查 16 维 state/action、state 和三张图均不晚于 action 且未过期，并使用 rosbag2 Reader 反序列化图像消息，确认每个图像索引确实存在于当前 bag。

测试期间定位并修复了 ROS 回调顺序导致的样本时间误判，改用有界历史缓存；同时保存 episode 起始观察上下文，保证索引引用图像存在于当前 bag。最早的失败日志保留在 log 中作为排错记录，最终结论以 build-final.log 和 test-final.log 为准。

软件集成测试范围：72Hz 合成 Quest UDP → 原坐标映射 → MuJoCo/Eigen IK → 控制阶段管理 → mock 双 OpenArm → 三路 mock JPEG → rosbag2 和样本索引 → HTTP Range → 下载中断续传 → SHA256 校验。还检查断流保持、不回放缓存、不在重连时自动运动、返回后失能。

## 验证边界

- 真实 Quest 头显操控体验、真实机械臂运动和电机反馈尚未测试。
- USB 模块接收测试未观察到总线帧；不能宣称物理 CAN 收发、接线、终端电阻和电机协议全部验收通过。虚拟 CAN 往返只验证软件 SocketCAN 链路。
- 海康 MV3D RGB-D ARM64 SDK、正式头文件及三台相机未提供。C++ 包装及假 SDK ABI/像素测试可以通过，但实际 ABI、设备时钟、图像格式和曝光同步仍待验证。
- 当前数据为双臂 16 维；没有编造 R680 和 Lift 的 5 维反馈。底盘/升降协议、21 维扩展及训练都不在本次实现中。
- 局域网协议以本机 HTTP/ROS 进程间测试验证；跨机器 WLAN 吞吐和长时间丢包测试尚未进行。
- mock 数据位于 build/test_runs，仅供测试，不能与实机采集数据混用。
