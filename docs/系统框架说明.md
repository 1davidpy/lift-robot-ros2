    SDK --> S["设备状态与故障汇总"]
    BASE --> S
    LIFT --> S
    S --> M
这里有两个关键实现约束。
第一，每个执行器只保留一个有效的控制命令出口。
如果正式系统采用官方 openarm_hardware 接入控制器，就不要同时运行另一个直接调用 openarm_can 的程序控制同一条机械臂。底层调试 demo 应在正式控制进程退出后运行。
第二，接收频率和设备控制周期分开。
Quest 数据经 Wi-Fi 到达的时间会变化。接收层更新“最新有效目标”，本地控制循环按照自己的周期执行，并检查目标是否过期。不能每收到一个网络包，就直接向所有电机发一次命令。
