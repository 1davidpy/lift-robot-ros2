## 行为

- 双臂仍在 Quest 150 ms 不新鲜时冻结已提交目标，包括归位/正常失能中的返回；新输入及所需的新 IK 目标到达后恢复。
- 底盘仍在 200 ms 断流时发送零速度；升降仍在 200 ms 时关闭主机 CAN 会话并取消该次有限移动。保留短时断流后的许可，不延长运动截止门槛。
- 断流超过 500 ms，仍锁定停止并要求明确重新使能；B、无效追踪、驱动反馈失联、CAN 严重故障和协调器丢失仍走原停止路径。
- 短时恢复后，底盘需要新的居中摇杆消息持续覆盖至少 100 ms，升降需要新的双握键释放消息持续覆盖至少 100 ms。保持旧摇杆/握键不会自动重放运动；之后分别接受新摇杆动作/新握键按下。
- 恢复回调在定时器之前执行时，也根据上一条输入时间检查断流长度，不能用新的接收时间掩盖长断流。
- X 长按不再被 150–200 ms 短间隙清除；长断流仍重置按键序列，需先松开 X。明确的 B 停止不受宽限期影响。
- 非统一模式保留现有 200 ms 撤销许可行为。旧的显式升降 HOME 请求在断流时仍取消，不自动重放；正常 X 停放不调用 HOME。
