# 配置2：七舵机上位机

双击本目录QtCenters.exe。scripts/build.cmd每次构建、运行四项自动测试并更新本目录exe、
Qt运行库、插件、config2.json，不需要手动设置PATH。复制程序时同时复制旁边DLL和插件。
构建使用Qt6.8.3 SerialPort、MinGW13.1及STM32Cube CMake/Ninja。

默认配置../excavator_controlled_servo/config/config2.json，独立部署使用旁边config/config2.json。
旧machines.json保留作历史。保存文件不自动下发或烧录；永久配置需重新构建、烧录接收端。
配置2：1号1001..2950、2号2223..4076、3号1547..3609、8号172..1292，均启用。
保存同时保留reference_mode/encoder_offset，防止模式切换后读数坐标变化改变机械限位含义。

遥控：LY→2、RY→1、RX→8、BL/BR→3、LX→4；大臂250、小臂500、俯仰/夹爪200，回转1000、履带3000。
BL+BR同时按后退，此时俯仰停止；按键不调速。
七轴在线mask191，四轴限位mask23；离线显示“--”。
界面反馈为标定参考坐标，原始寄存器可用POSITION_DIAG查询。

## 使用

1. 连接COM6，115200 8N1，确认有效反馈。
2. 若模式未准备，支撑大小臂和夹爪、履带架空、回转线缆安全、遥控中立，点击“准备遥控”。
   此操作短暂卸力，等待模式/反馈稳定并校验参考位置不变，再恢复力矩；不回旧中心。
3. 中立1秒后可遥控。越界轴只允许向范围内缓慢回退，禁止向外或跳到限位。
   遥控目标每20ms推进5/10/4/4、跟随窗口96；Qt手动仍限速度100、每次最多10。
4. 手动标定先暂停遥控。可在Flash范围内设置更小的RAM范围，点击该轴“准备标定”后，
   用±10或目标移动，速度1..100。前一目标未到附近±6时拒绝叠加；新目标仍须距实时位置不超过10。
5. 手动结束点击“恢复遥控”；模式已正确时无需重复卸力，仍需中立1秒。
   “恢复”限位按钮恢复Flash默认值。“全部停止”保持已运动位置轴并令底盘零速，暂停遥控。

取当前位置只填输入框；加载/保存不移动。上位机底盘动作及键盘运动保持禁用。
正常退出/断开/失焦时尝试停止；通信故障下不保证串口命令送达。
接收端失联保护保留，软件不能替代动力断电。

实机记录：../excavator_controlled_servo/docs/hardware_test_2026-10-15.md。

自动测试不打开串口。单独执行build-release/bin/qt_centers_serial_smoke.exe COM6：
检查通信、七舵机在线、Flash配置，临时缩小并恢复ID1 RAM限位，以及停止回复。
不准备位置轴、不执行位置运动；该检查会暂停遥控。
--protocol-only不要求在线、不改RAM限位，仍发送停止。测试后可手动恢复遥控。
