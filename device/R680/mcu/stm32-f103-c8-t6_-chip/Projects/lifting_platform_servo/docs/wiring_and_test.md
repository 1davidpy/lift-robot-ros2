# 接线与测试入口

当前固件 v31 使用 UART 二进制协议和原生PP连续加减速，只保留 PB14 中心光耦和 PA6 抱闸继电器。完整接线、标定、帧格式、命令、遥测、Python 主控程序和验收步骤统一见：

[UART外设接口手册：RDK X5 USB接入、完整命令与Python客户端](UART机器人升降平台外设接口_RDKX5.md)

[维修接线、SWD与标定备份恢复（历史文件名）](CAN机器人升降平台使用手册.md)

旧版多光耦限位、CAN 总线和 ASCII 串口命令均已停用，不应再按历史测试记录接线或控制。

LED1/PB12在电机通信正常时以1 Hz闪烁，通信异常/过期时灭；LED2/PB13独立以1 Hz闪烁表示MCU指示任务在运行，与电机是否在线无关。抱闸状态通过UART flags.bit2查看。LED3不作软件指示，PB14继续接中心光耦；PB13不能再接光耦或其他输出。
