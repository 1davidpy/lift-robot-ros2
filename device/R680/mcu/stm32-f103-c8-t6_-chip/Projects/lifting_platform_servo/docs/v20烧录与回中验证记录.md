## 实机结果

所有位置均为控制器编码器换算的反馈值，不是外部量具精度认证。各次完成后继续观察至少5秒，均保持锁闸、无驱动故障、无串口所报驱动通信错误、无保护锁定。

| 测试 | 结果 | 串口采样最高转速绝对值 |
|---|---|---:|
| 中心处烧录后启动 | 0.000 mm，锁闸，版本20 | 0 rpm |
| 0 → +50 mm | +50.000 mm，到位 | 2245 rpm |
| +50 → −20 mm | −20.000 mm，到位 | 2622 rpm |
| −20 mm处MCU复位 | 自动恢复参考并返回0.000 mm，未向下搜索限位 | 1337 rpm |
| 复位后0 → +100 mm | +100.000 mm，到位，控制仍有效 | 3016 rpm |
| +100 → 0 mm | 0.000 mm，到位并保持锁闸 | 3042 rpm |

四次串口目标运动均使用3000 rpm速度上限，日志中的非零`segment_rpm`为3000；短行程受加减速影响，未必达到巡航上限。串口有采样间隔，表中峰值不是连续高速采样得到的真实最大值；3042 rpm仍在现有5%反馈转速容差内，未触发超速保护。
