# ISL60-PR 纯 RS485 连续 JOG 调试报告

日期：2026-09-07

## 固件功能

- K1 按住：顺时针连续转动；松开：RS485 停止。
- K2 按住：逆时针连续转动；松开：RS485 停止。
- 两键同时按下：停止并锁定，全部松开后才重新允许启动。
- 换向时先停止，等待 1.1 秒后再启动相反方向。
- 上电不自动转动；必须先检测到两键均松开。

## 在线验证

- ST-LINK：`10004400180000513751594E`
- MCU：STM32F103C8T6，目标电压 3.24 V，内核运行正常。
- 固件状态：`READY(2)`。
- Modbus 结果：0；异常码：0；通信错误计数：0。
- 驱动器故障码 P0B-34：0；实际转速 P0B-00：0 rpm。
- 实际方向参数 P02-02：0（CCW 为正方向）。
- K1 顺时针映射：P0D-08=32（JOG-）。
- K2 逆时针映射：P0D-08=16（JOG+）。
- 空闲请求/当前控制字：256（停止）。

Debug ELF 已烧录并校验。在线检查期间没有模拟按键，电机保持停止；实际按键持续运动由操作者在确认轴和机构安全后执行。
